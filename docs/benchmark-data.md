# Benchmark Data

Local evaluation data is stored under `dataset/`. Only `dataset/CLAUDE.md` is tracked in Git; downloaded datasets and upstream source are ignored.

## Layout

```text
dataset/
├── <dataset-name>/       Downloaded source data
├── .upstream/            Upstream AML pipelines and judge source
├── .legacy/              Non-runnable archive material
└── .tmp/                 Atomic download and patch workspace
```

The authoritative manifest is [`eval/datasets/manifest.py`](../eval/datasets/manifest.py). It records source URLs, revisions, expected hashes, and declared local patches. [`eval/datasets/layout.py`](../eval/datasets/layout.py) maps manifest names to local paths.

## Prepare and Validate

```bash
uv run python -m tianximem.dev data-fetch --dataset locomo-refined
uv run python -m tianximem.dev data-check --dataset locomo-refined
```

Other useful forms:

```bash
uv run python -m tianximem.dev data-fetch --dataset all
uv run python -m tianximem.dev data-check --dataset all
uv run python -m eval.datasets.prepare --list
uv run python -m eval.datasets.prepare --fetch --tier required --offline
```

The preparation flow is:

```text
select dataset
  -> download missing files into an isolated temporary directory
  -> verify upstream hashes
  -> apply only declared local patches
  -> verify local hashes
  -> atomically publish
```

A failed download or hash check publishes nothing. Existing checked files are reused. `--offline` never downloads.

The data root comes from `TIANXIMEM_BENCHMARK_DIR`; the default is `dataset`.

## Input Contracts

`--input-contract native` uses each dataset's native loader and answer/judge pipeline. It is the default.

`--input-contract aml-v1` uses the AML-oriented event planners under `eval/datasets/aml/`. These planners preserve native questions and scoring while constructing Add and Search events that resemble AML traffic.

The AML-oriented path may synthesize timestamps, split long source items, and choose a deterministic order. These choices are recorded in the run's input manifest. They are local approximations and are not guaranteed to match platform tokenization or captured request boundaries.

Datasets without a reliable mapping continue to use `native`; they do not silently claim `aml-v1` compatibility.

## Upstream Pipelines

Official AML pipeline code is stored under `dataset/.upstream/aml/`. Evaluation I/O follows those scripts, not dataset README prose, when the two differ.

Some upstream files require a small mechanical patch to run on the repository's Python version. Every patch is declared in the manifest and checked by `tests/test_benchmark_archive.py`. Prompts and scoring logic are not modified by these patches.

## Official Capture

The raw official request capture is generated by the service and is not reconstructed by the public-data downloader. Replay uses the original captured Add and Search payloads and follows their timeline.

Use [`capture-evaluation-pipeline.md`](capture-evaluation-pipeline.md) for replay and comparison.

## Fixed Selection Suite

Use [`fixed-selection-suite.md`](fixed-selection-suite.md) when multiple people must evaluate the same fixed set of question IDs.

## Licensing and Data Handling

- Keep downloaded data and captured requests out of Git.
- Do not redistribute captured evaluation traffic.
- Do not train or fine-tune models on evaluation data.
- Follow each upstream dataset license.
- Treat manifest hashes as the authoritative byte identity for local evaluation inputs.
- Do not modify downloaded source bytes outside a manifest-declared patch.

## Troubleshooting

| Symptom | Cause | Action |
| --- | --- | --- |
| Hash mismatch | Wrong source revision or local edit | Re-fetch the declared revision; do not update the hash by hand. |
| Offline preparation fails | Required file is absent | Run once online for that dataset. |
| Dataset is not selectable | It is not registered in the manifest | Add a source definition and loader before using it. |
| Local score is not comparable | Different question IDs, data hash, add shape, model, budget, or judge | Start a new run ID with a complete fingerprint. |
