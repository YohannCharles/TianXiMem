**CorporateBench：只替换记忆内容的可回答性诊断（2026-10-04）**

按用户要求，后续产品改动限定为 **Add/Search，输出原始片段或抽取的事实记忆**。
Search 不生成答案，也不返回按题目预先计算的计数或名单。本轮先验证答案模型能否使用
正确相关的证据；未修改服务、答案模板或评分器，未实施 Add/Search 改进。
上一轮答案侧代码聚合的建议已撤回。

**结论：独立事实明显改善了非空列表，但计数与否定问题仍有瓶颈。**
严格匹配条件的事实组，人工核对后列表完全正确 8/12、计数正确 6/12；仍出现
12 人数成 13 人、11 场数成 13 场，以及只有一条明确发生事实却拒答的情况。
因此，不能将所有错误归因于召回，也不能承诺仅靠缩短上下文就解决计数。

**实验口径**

- 固定 Zenith `kb_qa` 的 24 道定向诊断题：12 道 `int`、12 道 `List[str]`。
  含历史错例和正向对照；列表中 9 道非空、3 道空集合，计数中 1 道为零。
  这是人工选题后的局部诊断，不是全量 250 题的新分数。
- 固定 `base-cb` 原始通用 `ANSWER_PROMPT`，未使用上一轮新增的类型化模板。
  模型为 `Qwen/Qwen3.5-9B`，`temperature=0`，输出上限 1024 token。
  原模板要求仅用记忆、缺答案则拒答、简短作答，不包含列表 JSON 输出要求。
- 基线复用这 24 题的历史答案，采用本轮冻结的已有评分器重判。
  对照组只改传入的记忆正文，题目、金标与判断口径不变。
- 没有把 `questions.answer` 写入记忆，没有提供聚合数字、答案名单或答案生成指令。
  每个片段描述独立对象或事件，并保留来源。
- `graph.nq` 和题目的 `variables` **只用于离线 oracle 选源、关系定位和条件筛选**。
  事实包含原文没有明确表达的 KB 类型、时序和关系；不代表现有 Add 能忠实抽取这些内容。
  这项测试也没有验证自然语言题目解析能力。

固定题号：

```text
int:       0, 3, 5, 6, 12, 26, 37, 51, 87, 88, 148, 228
List[str]: 4, 7, 9, 15, 17, 32, 35, 49, 135, 190, 220, 221
```

```text
Source: email_Technical_Debt_Management_4076.txt
```

它支持“明确关系和时间能改善列表”的方向。但上面日期取自 KB 时序标注，原文只含
“commenced my role”或 orientation 的间接线索；正式 Add 必须保留支持程度，不能将
普通通信日期替代为入职日期。

12 条单人任职事实，仍报 13。它们的错答不能用“日期筛错”或“材料太长”解释。

`kb_qa-12` 最后一组已经写明：

```text
The "Task: release readiness validation suite" meeting occurred on 2024-02-21.

```

**在 Add/Search 边界内的后续方案**

1. **Add 保存可追溯的独立事实。** 提取人物—任职、会议—时间/主题/项目、会议—参与者
   等关系；每条带原文出处、事件身份及时间语义。区分文档发送、计划召开、实际发生，
   区分收件人、组织者、参加者；只有原文明确支持的字段才能写成确定事实。
2. **Search 识别条件并选择事实。** 从自然语言题目提取对象、关系、日期和频率，依据
   索引筛选并核对来源；同一事件的重复提及合并，独立事件各保留一份必要证据。
   可返回键值事实或原文证据片段，不返回计算出的次数或最终名单。
3. **否定题先验证表示是否充分。** 需要明确候选范围、有效时间和实际来源覆盖。
   范围声明只能来自真正完成的索引核对；不能用“搜索没命中”或“结果饱和”冒充完备。
   本轮加 oracle 完整范围声明并未改善空集题，不应据此仅加一句覆盖声明作为修复。
4. **再测自动事实与 oracle 的差距。** 用相同题、原始答案模板及模型验证从原文自动
   抽取/筛选的片段，记录抽取忠实性和答案质量，再进行全量回归。计数仍可能受当前
   答案模型限制；本轮没有测试提交时的其他答案模型，也未证明 Add/Search 可消除全部错误。

本轮同时否定了两种捷径：盲目补更多原文没有得到支持；仅换自然语言事实或加入
范围声明也没有稳定改善。本地 oracle 的结果只说明理想证据下的可回答性，不能作为
真实检索收益、事实抽取精度或 AML 榜分。
