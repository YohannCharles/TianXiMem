# embed/ — Embedding 后端

**PRD**：§7.4（接口）、§7.2（缓存与索引/查询两侧）、§2.3（模型规定）

## 要写什么

```text
base.py               Embedder 协议
text_embedding_v4.py  提交与本地评测用（§2.3 唯一允许的 embedding 模型）
bge_m3.py             对照实验用（开发期，**不进提交链路**）
```

## 接口（§7.4）

```python
class Embedder(Protocol):
    dim: int
    def encode(self, texts: list[str]) -> list[list[float]]: ...
```

> **代码中不得出现任何依赖具体模型输出结构的逻辑。**

`dim` **由接口提供、不能写死**。Step 5 换模型时按新维度**重建集合**（§2.3 / §16）。

---

## 为什么这个抽象是硬要求，不是好品味

§2.3 的规定推出一条设计约束：

> **架构必须 embedder-agnostic。** `text-embedding-v4` **不提供 sparse 或 ColBERT 输出**，因此**任何依赖 BGE-M3 多向量能力的代码在提交时都是死重**。

开发期用 BGE-M3 只是**控 API 成本的临时手段**（§12.1 R1）。若代码里渗入了它的多向量能力，Step 5 就不是"换一个实现"，而是"删掉一批代码并重写调用方"。

**同理**：词法那一路**不要用 BGE-M3 的 sparse 输出**——理由有二：它的 sparse 是**学出来的词法权重而非 BM25**；且**提交时的 `text-embedding-v4` 不提供该能力**（§7.1）。词法走 Qdrant 原生 `qdrant/bm25`。

## 两侧的输入必须不同，且各有约束

| | 索引侧 | 查询侧 |
| --- | --- | --- |
| 输入 | 一个 QA 对的**渲染文本**（§11.3），**一对一个向量** | **query 原样送进去** |
| 改写 | —— | **不做任何改写**——v1 没有 Query Analyzer，查询改写属 v2 |
| 调用次数 | 每个对 1 次（缓存后趋近 0） | **每查询恰好 1 次** |

> **查询侧"不做改写"是 v1 的规格，不是省略。** §5 明确区分了两件事：图里的"关键词重写"是 **Agent 每轮自己产出的检索关键词**（属于 agent 循环，v1 **有**）；而**检索之前那一次独立的 query 改写属 v2，v1 没有**。

**索引侧的渲染必须是 `common/render` 的那一份**——§7.2 与 §11.3 要求 embedding 的输入与返回给 AML 的 `content` 是**同一份渲染**。`embed/` **不自己拼字符串**。

## 缓存（§7.2）

| 要求 | 说明 |
| --- | --- |
| **缓存键 = 渲染后 QA 文本的哈希** | **不能用 `id`**——补全时内容变了而 `id` 不变，用 `id` 会拿到**陈旧向量** |
| **必须落盘** | 否则每次重启重付一遍 |
| **能整体失效** | Step 5 切模型时要能一次性作废（§12.1 R1 对冲 1） |

> **为什么这条是 R1 对冲的核心**：v1 的 Add 阶段**不调用任何 LLM**，embedding 是**唯一的 Add 侧成本**，且**只与内容有关**——**缓存后即成为一次性成本，与迭代次数无关**。若缓存没落盘，每次改检索逻辑重跑 harness 都要把整个数据集重新 embed 一遍，**成本随迭代次数线性增长**，而迭代是本项目做得最多的事。

**缓存键的坐标系要写进缓存文件本身**（模型名 + 维度 + 渲染模板版本）——否则 Step 5 切换后**旧缓存会静默命中**，拿 BGE-M3 的向量去查 `text-embedding-v4` 的集合，而**维度不同只会表现为"检索结果很差"，不会报错**。

## 模型规定（§2.3，不可协商）

| 组件 | 规定 |
| --- | --- |
| **Embedding** | **只能用 `text-embedding-v4`** |
| **LLM 相关组件** | **只能用 `gpt-4o-mini`** |
| **Reranker** | **不作规定** |

**开发期替换是团队主动接受的偏离**（§12.1 R1）——代价是**本地标定出的所有阈值、权重、排序策略在切换后都不保证成立**。四条对冲见 [`../../docs/decisions.md`](../../../docs/decisions.md) D2。
